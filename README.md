# Calculator

A simple Python calculator with basic arithmetic operations.

## Functions

- `add(a, b)` — returns a + b
- `subtract(a, b)` — returns a - b
- `multiply(a, b)` — returns a * b
- `divide(a, b)` — returns a / b (raises ValueError if b is 0)

## Running tests

```
pytest test_calculator.py
```
