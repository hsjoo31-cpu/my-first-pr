# 백테스트 검증 기록 (BTC 선물 자동매매)

BTCUSDT.P(바이낸스 USDT-M 선물) 대상으로 여러 자동매매 전략을 백테스트한
결과를 기록합니다. **같은 삽질을 반복하지 않기 위한 문서**입니다.

> 핵심 교훈 먼저: **단순 룰 기반 분봉 자동매매로는 BTC에서 수수료를 이기는
> 견고한 우위를 찾지 못했다.** 테이커 수수료에선 전부 손실, 메이커(지정가)
> 가정에서 일부가 겨우 플러스였으나 그마저 연 1% 수준이고 6개월 단위로는
> 운에 좌우됐다.

## 3. 분석 / 결론

1. **수수료가 결정적.** ORB의 gross(수수료 전) 엣지는 +8~9%/년으로 실재했으나,
   테이커 왕복 0.12%(145거래 ≈ −16%)에 잠식돼 net 손실. 메이커 0.04%로 낮추자
   비로소 +2.55%로 전환. → **이 전략의 수익성은 "메이커 완벽 체결"에 전적으로 의존.**

2. **엣지는 진짜지만 너무 작다.** 6.75년·835거래에서 승률 54.85%로 일관 →
   과최적화·운이 아닌 통계적 우위 존재. 그러나 **연환산 +0.9%**로 경제적 의미 없음.

3. **6개월 단위는 운.** 인접한 두 6개월이 승률 49% vs 65%, PnL −3.45% vs +7.46%로
   정반대. 견고한 엣지라면 비슷해야 함. → 단기 성과는 시작 시점 복불복.

4. **상한선 주의.** 위 플러스 결과는 TradingView가 청산(liquidation)을 모델링하지
   않고 지정가가 항상 체결된다고 가정한 **이상적 상한**. 실거래에서는:
   - 돌파 지정가 미체결 → 이긴 거래를 놓쳐 얇은 엣지 소멸 위험
   - 손절은 보통 시장가(테이커) → 추가 비용
   - 고배율 시 청산 위험
   → 실제 성과는 연 0.9%보다 **더 나쁠 가능성**이 높다.

## 4. 권고

- **단순 룰 기반 분봉 단타는 구조적으로 수수료·복불복에 불리.** 이 방향은 종료 권장.
- 대안으로 고려할 만한 것: 거래가 드물어 수수료 영향이 작은 **일봉/주봉 추세추종**,
  또는 **DCA(분할매수)+리밸런싱** 등 화려하지 않지만 작동하는 방식.
- 어떤 전략이든 **Buy & Hold 벤치마크**를 이기는지, **기간 분할(out-of-sample)**에서
  일관된지를 반드시 확인할 것. (이번 검증에서 이 절차가 진실을 가렸다.)
